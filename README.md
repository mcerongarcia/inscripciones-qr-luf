# Inscripciones QR LUF

Formulario público rápido para la inscripción a actividades del Liceo Luis Urbina Flores.

- La interfaz pública se ejecuta en GitHub Pages.
- Los datos se registran mediante Google Apps Script.
- Cada persona recibe un código QR individual.
- La administración y el control de acceso permanecen en la aplicación privada.

Página pública: https://mcerongarcia.github.io/inscripciones-qr-luf/
